# 💼 React Portfolio

A personal developer portfolio built with **React** and deployed to Netlify. Showcases my projects, skills, and background as a full-stack JavaScript developer.

---

## 📖 Overview

This portfolio was built as a single-page application using React, replacing a previous static HTML/CSS version. It demonstrates component-based architecture, React Router for navigation, and a clean professional design — everything a hiring manager or client would want to see at a glance.

---

## ✨ Features

- ⚛️ **Single-page app** with smooth client-side navigation via React Router
- 🗂️ Dedicated pages: About Me, Portfolio, Contact, Resume
- 📬 Contact form with basic validation
- 🔗 Links to live project demos and GitHub repos
- 📄 Resume download link
- 📱 Fully responsive layout

---

## 🛠️ Tech Stack

| Technology          | Purpose                      |
| ------------------- | ---------------------------- |
| React               | Component-based UI framework |
| React Router        | Client-side routing          |
| CSS / Inline Styles | Styling and layout           |
| Netlify             | Deployment and hosting       |

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)

### Installation

```bash
# Clone the repository
git clone https://github.com/Voobane/C20.git
cd C20

# Install dependencies
npm install

# Start the development server
npm start
```

Visit `http://localhost:3000` in your browser.

### Build for Production

```bash
npm run build
```
